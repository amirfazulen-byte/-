# «ОтветБот»: черновики ответов на отзывы и вопросы Wildberries

Первая версия для пилота с 10–15 селлерами. Только Wildberries: API отзывов Ozon, по данным Ozon, доступен лишь при подписке Premium Plus.

## Как работает

1. Селлер открывает бота по ссылке-приглашению и присылает API-токен WB с категорией «Вопросы и отзывы». Категория «Контент» необязательна: с ней бот видит размеры и характеристики из карточек. Токен проверяется запросом к WB, хранится зашифрованным, а сообщение с ним удаляется из чата.
2. Раз в 15 минут бот забирает неотвеченные отзывы и вопросы. При подключении он берёт до 30 уже накопившихся, чтобы селлер сразу увидел результат.
3. Claude пишет черновик по данным карточки и в стиле селлера (`/style`). Имя покупателя в запрос не передаётся.
4. Каждый черновик приходит в Telegram с кнопками «Опубликовать / Изменить / Пропустить». Если черновиков без пометок несколько, приходит ещё кнопка «Опубликовать все без пометок».
5. **Ничего не публикуется само.** Исключение — `/auto`: тогда без подтверждения уходят ответы на 5★, где не сработала ни одна проверка.
6. Раз в неделю приходит сводка: товары с негативом, частые жалобы («маломерит», «брак», «запах»…) и товары, о которых чаще всего спрашивают.

### Двойная защита от опасных ответов
- **Claude** по инструкции ставит пометку «⚠️ нужно ваше решение» при браке, возврате, здоровье, детской безопасности, юридических претензиях и если ему не хватает данных.
- **Код** после этого перепроверяет каждый черновик и ставит пометку, даже если Claude её не поставил:
  - в ответе есть обещания: «вернём», «замена», «скидка», «промокод», «лечит», «сертификат»;
  - в отзыве есть чувствительные темы: аллергия, беременность, безопасность, Роспотребнадзор, суд, подделка;
  - товар из категории БАД или лекарства;
  - в ответе есть число, которого нет ни в карточке, ни в отзыве (защита от выдуманных размеров).

## Команды
Для селлера:
- `/style` — образцы своих ответов;
- `/auto` — автопубликация 5★;
- `/status` — лимит и состояние;
- `/pause`, `/resume` — приостановить и продолжить;
- `/token` — заменить токен.

Для оператора (`ADMIN_TG_ID`):
- `/stats` — по каждому селлеру: сколько черновиков, сколько опубликовано без правок и с мелкими правками (это главная метрика «продолжать или нет»), сколько с пометкой, сколько пропущено;
- `/setlimit <tg_id> <N>` — лимит ответов в месяц (по умолчанию 100, бесплатный тариф).

Оплаты в боте пока нет: на пилоте селлер платит переводом, а оператор поднимает лимит через `/setlimit`.

## Запуск
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
cp otvetbot.env.example .env   # заполните BOT_TOKEN, ANTHROPIC_API_KEY, TOKEN_ENCRYPTION_KEY, ADMIN_TG_ID
set -a; . ./.env; set +a
.venv/bin/python -m otvetbot.bot
```
Тесты: `.venv/bin/pip install pytest && .venv/bin/python -m pytest tests/test_otvet_*.py`

## ⚠️ Важно до пилота

### 1. Стоимость модели
По умолчанию стоит `claude-opus-5-5`. Запрос на один черновик — примерно 900 входных токенов и 200–400 выходных. Оценка грубая, проверьте по `usage` на реальных отзывах:

| Модель | Цена за 1 млн токенов (вход/выход) | Примерно за черновик | 1000 черновиков |
|---|---|---|---|
| `claude-opus-5-5` (по умолчанию) | $4 / $20 | ~$0.01 (~1 ₽) | **~1000 ₽** |
| `claude-sonnet-5-5` | $2 / $10 | ~$0.005 (~0.4 ₽) | ~400 ₽ |
| `claude-haiku-5-5` | $0.10 / $0.50 | ~$0.0003 (~0.03 ₽) | ~30 ₽ |

При тарифе 990 ₽ за 1000 ответов на Opus расходы на ИИ съедят всю выручку. Решение за вами: сравните качество черновиков на 50–100 реальных отзывах и выберите модель через `CLAUDE_MODEL`. Для модели Haiku резервная модель при отказе не подключается: такой черновик просто уходит селлеру с пометкой.

### 2. Доступность Claude API и персональные данные
Anthropic не обслуживает клиентов из России, поэтому ключ API и оплату нужно оформить так, чтобы это было законно для вас. Кроме того, текст отзывов уходит на серверы за рубежом. Имена покупателей бот не передаёт, но в тексте отзыва изредка встречаются личные данные. Покажите схему юристу. Если нужна модель с серверами в РФ, вся работа с ИИ собрана в `otvetbot/drafter.py`, менять придётся только этот модуль.

### 3. Правила API WB
Методы взяты из документации WB «Вопросы и отзывы»: `GET /api/v1/feedbacks`, `GET /api/v1/questions`, `POST /api/v1/feedbacks/answer`, `PATCH /api/v1/questions`; лимит около 3 запросов в секунду. Перед пилотом прочитайте актуальные условия использования API на dev.wildberries.ru: не запрещены ли ответы, подготовленные сторонними сервисами. Проверьте и запрос карточек (`/content/v2/get/cards/list`): его формат я восстановил по памяти и на настоящем WB не проверял. Если он не сработает, бот всё равно будет работать, только по данным из самого отзыва.

### 4. Сервер
Нужен VPS с ежедневным бэкапом `otvetbot.db`. `TOKEN_ENCRYPTION_KEY` храните отдельно от базы. Unit-файл для systemd — как в корневом README, только с `-m otvetbot.bot`.
